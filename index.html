Kirim Langsung ke Google Sheets (Opsional)

Hubungkan ke Spreadsheet Anda menggunakan URL Web App Google Apps Script

Cara Cepat (3 Langkah):
  1. Buka Google Sheets baru, lalu klik menu Ekstensi → Apps Script.
  2. Hapus kode lama, tempel skrip di bawah ini, lalu klik Terapkan (Deploy) → Deployment baru → Aplikasi Web (Akses: Siapa saja / Anyone).
  3. Salin URL Aplikasi Web yang muncul, tempel pada kolom di bawah, lalu klik Kirim Semua Data.
Kode Google Apps Script Siap Pakai: 
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var payload = JSON.parse(e.postData.contents);
  if (sheet.getLastRow() === 0 && payload.headers) {
    sheet.appendRow(payload.headers);
  }
  (payload.rows || []).forEach(function(row) {
    sheet.appendRow(row);
  });
  return ContentService
    .createTextOutput(JSON.stringify({ status: "ok" }))
    .setMimeType(ContentService.MimeType.JSON);
}
